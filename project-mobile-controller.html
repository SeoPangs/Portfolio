01 · OVERVIEW

프로젝트 개요

스마트폰을 로컬 네트워크 게임 컨트롤러로 사용하는 프로토타입입니다. 모바일 입력을 정규화해 전송하고 Unreal Engine에서 패킷을 해석한 뒤 Enhanced Input과 연결했습니다.

02 · IMPLEMENTATION

핵심 구현

  • 경량 UDP 입력 패킷
  • 시퀀스 번호를 이용한 오래된 패킷 폐기
  • 입력 보간과 데드존 처리
  • 연결 타임아웃 및 자동 복귀
  • 교체 가능한 입력 수신 컴포넌트

02UDP Receiver
03Enhanced Input

03 · PROBLEM SOLVING

문제 해결 과정

문제

Wi-Fi에서 패킷 순서가 뒤바뀌거나 누락되면서 캐릭터가 반대 방향으로 움직이거나 입력이 고정되는 현상이 있었습니다.

해결 방법

패킷에 시퀀스 번호와 송신 시간을 포함하고 이전 번호는 폐기했습니다. 일정 시간 새 패킷이 없으면 입력값을 0으로 복귀시켰습니다.

결과일시적인 패킷 손실에서도 입력 고정 현상을 제거했습니다.

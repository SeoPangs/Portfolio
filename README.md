# 게임 프로그래머 포트폴리오 예시

## 실행 방법
1. 압축을 풉니다.
2. `index.html`을 브라우저에서 엽니다.
3. 실제 배포 시 GitHub Pages, Vercel, Netlify 등을 사용할 수 있습니다.

## 반드시 교체할 부분
- 이름, 이메일, GitHub 및 블로그 주소
- 프로젝트 설명과 수치
- 프로젝트 이미지
- 이력서 PDF
- 기술 스택과 경력 정보

## 추천 프로젝트 상세 페이지 구성
- 프로젝트 개요
- 담당 범위
- 핵심 구현 영상
- 구조도 또는 클래스 다이어그램
- 문제 상황 / 원인 / 해결 / 결과
- GitHub 코드 링크
- 회고

포트폴리오에서 가장 중요한 것은 디자인보다 실제 플레이 영상, 본인 담당 범위,
코드 구조, 문제 해결 과정입니다.

void UCombatComponent::TryAttack()
{
    if (!CanAttack()) return;

    FGameplayEventData EventData;
    EventData.EventTag = AttackTag;

    UAbilitySystemBlueprintLibrary::
        SendGameplayEventToActor(
            GetOwner(),
            AttackTag,
            EventData
        );
}

CASE 01 멀티플레이 이동 불일치

문제

보드게임 이동 중 클라이언트마다 캐릭터 위치가 달라지는 현상이 발생했습니다.

원인

각 클라이언트가 자체 보간을 수행하고 이동 종료 시점을 개별 판정하고 있었습니다.

해결

서버가 이동 경로와 시작 시간을 확정하고, 클라이언트는 동일한 타임라인을 재생하도록 변경했습니다.

RESULT 위치 오차 평균 42cm → 3cm 이하
CASE 02 스킬 코드 중복 증가

문제

캐릭터가 늘어날수록 공격 스킬 클래스와 예외 분기가 빠르게 증가했습니다.

원인

공격 판정, 이펙트, 자원 소모가 하나의 클래스에 강하게 결합되어 있었습니다.

해결

공통 실행 흐름은 Ability에 두고 세부 동작을 데이터와 태스크 조합으로 분리했습니다.

RESULT 신규 스킬 제작 시간 약 50% 감소

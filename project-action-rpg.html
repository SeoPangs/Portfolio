PROJECT 01 · ACTION RPG

모듈형 액션 RPG 전투 시스템

Gameplay Ability System을 기반으로 공격, 콤보, 피격, 상태 이상을 데이터 중심으로 구성한 전투 프로토타입입니다.

YouTube 영상, MP4 또는 GIF로 교체하세요.

01 · OVERVIEW

프로젝트 개요

액션 RPG에서 반복적으로 필요한 전투 기능을 재사용 가능한 프레임워크로 구성했습니다. 공격 판정과 애니메이션, 자원 소모, 상태 변경을 개별 캐릭터 클래스에 직접 작성하지 않고 Ability와 Task, 데이터 에셋의 조합으로 표현했습니다.

Unreal C++Gameplay Ability SystemGameplayTagAnimation MontageData Asset

02 · IMPLEMENTATION

핵심 구현

  • GameplayTag 기반 공격 상태 및 입력 버퍼
  • AbilityTask 기반 몽타주·노티파이·판정 동기화
  • GameplayEffect 기반 피해량과 상태 이상 처리
  • Primary Data Asset 기반 스킬 데이터 관리
01Ability System
02Ability / Task
03Effect & Data

03 · PROBLEM SOLVING

문제 해결 과정

문제

캐릭터마다 공격 클래스를 별도로 만들면서 판정, 자원 소모, 이펙트 실행 코드가 중복됐습니다.

해결 방법

공통 실행 순서는 기본 GameplayAbility에 두고 애니메이션과 공격 판정은 재사용 가능한 AbilityTask로 분리했습니다. 캐릭터별 차이는 태그와 데이터 에셋으로 주입했습니다.

결과신규 스킬 제작 시간이 예제 기준 약 50% 감소했습니다.

코드와 문서

온라인 파티 보드게임

01 · OVERVIEW

프로젝트 개요

서버가 게임 규칙과 상태 전환을 전담하고 클라이언트는 표시와 입력 요청을 담당하도록 책임을 구분했습니다.

02 · IMPLEMENTATION

핵심 구현

  • 서버 권한형 턴 매니저와 페이즈 상태 머신
  • 보드 노드 그래프 기반 이동과 분기 선택
  • PlayerState를 통한 점수·순서·아이템 동기화
  • 미니게임 레벨 전환과 결과 복귀 처리

03 · PROBLEM SOLVING

문제 해결 과정

문제

각 클라이언트가 이동 보간과 종료 판정을 개별 수행해 네트워크 지연 상황에서 위치와 턴 종료 시점이 달라졌습니다.

해결 방법

서버가 경로 배열과 이동 시작 서버 시간을 확정해 복제하고, 클라이언트는 동일한 서버 시간 기준 타임라인만 재생하도록 변경했습니다.

결과클라이언트 간 평균 위치 오차를 약 42cm에서 3cm 이하로 줄였습니다.
